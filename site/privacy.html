Privacy Policy

Fitsek collects only the information needed to run the fitness funnel: page analytics, first-party click, section-view and scroll-depth events, email signups, UTM/source tags, and basic social/business metrics. These metrics are used to improve the funnel, not to diagnose health or identify individual visitors.

Email

If you sign up, your email is used to send the free reset and Fitsek updates. You can unsubscribe or request deletion by contacting hello@fitsek.com.

Analytics

Fitsek uses privacy-aware analytics first, including Cloudflare Web Analytics and first-party event logging for visits, CTA clicks, section views, scroll depth, and signup events. We do not sell personal information.

Heatmap-style reporting is aggregated from first-party events. Fitsek does not currently run session recording or third-party heatmap playback. If Microsoft Clarity or similar recording tools are enabled later, masking and consent requirements must be reviewed first.

Data security

Lead data is stored in private runtime storage, not in this public repository. Secrets and API keys must never be committed.
