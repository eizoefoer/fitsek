Privacy Policy

Fitsek collects only the information needed to run the fitness funnel: page analytics, UTM attribution, email signup details you submit, and basic event data such as CTA clicks.

Email

If you sign up, your email is used to send the free reset and Fitsek updates. You can unsubscribe or request deletion by contacting hello@fitsek.com.

Analytics

Fitsek uses privacy-aware analytics first, including Cloudflare Web Analytics and first-party event logging for visits, CTA clicks, and signup events. We do not sell personal information.

Data security

Lead data is stored in private runtime storage, not in this public repository. Secrets and API keys must never be committed.
