# Meta + Fitness Compliance Policy

## Meta / Instagram / Facebook
- Start with Meta Business Suite/manual scheduling.
- API usage only with approved permissions and stable compliance.
- Do not bypass app review.
- Do not spam, mass-post, scrape, buy engagement, or manipulate engagement.
- Store Meta app ID, secret, access tokens, page tokens, and user tokens only in environment variables, GitHub Actions secrets, or a secure VM secret store.
- Log only non-sensitive metadata: timestamp, platform, draft ID, status, post URL/ID if public, and error category.
- Default to manual approval mode for first 30 days unless the user explicitly approves full auto-posting.

## Fitness/wellness safety
- General fitness/wellness education only.
- No guaranteed fat loss, no medical treatment, no diagnosis, no hormone/testosterone/cortisol/ferritin/ADHD claims.
- No fake before/after transformations or fake testimonials.
- AI-generated people must be illustrative only and never represented as real customers.
- Recommend qualified health professionals where appropriate.
