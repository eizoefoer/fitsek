# Social Approval Workflow

1. Draft posts in `content/social/posts/`.
2. Compliance-check each draft for medical claims, fake proof, and misleading transformation language.
3. Generate or select a faceless visual from `assets/social/` or a template.
4. User approves/edits.
5. Schedule manually in Meta Business Suite for Instagram and Facebook Page.
6. Record published URLs and metrics in `analytics/manual_social_metrics.csv`.
7. Weekly review updates the next week’s content calendar.

Auto-posting is disabled by default for the first 30 days.
