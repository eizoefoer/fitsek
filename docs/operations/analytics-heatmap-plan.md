# Fitsek analytics and heatmap operating plan

Last updated: 2026-07-10

## Current measurement stack

- **Cloudflare Web Analytics** is loaded on every public page for privacy-light traffic, referrer, country/device/browser, and Web Vitals-style top-of-funnel visibility.
- **First-party event API** at `https://leads.fitsek.com/event` receives site events from `site/app.js` and stores runtime JSONL under `/var/lib/fitsek` on the VM.
- **Lead API** at `https://leads.fitsek.com/signup` stores email signups privately under `/var/lib/fitsek`.
- **Business review reports** are generated by `automation/business_review.py` into `analytics/reports/`.
- **UX heatmap-style reports** are generated by `automation/heatmap_report.py` into `analytics/reports/`.

## First-party UX events

`site/app.js` emits:

- `page_view`
- `click` with `data-track` labels and hrefs
- `outbound_intent` for external links
- `section_view` for first view of each main section
- `scroll_depth` at 25%, 50%, 75%, and 90%
- `signup_success` / `signup_error`

This gives enough signal to answer: where do visitors drop, which sections get seen, and which CTAs get clicked.

## Heatmap stance

Fitsek does **not** currently run session recording, replay, or third-party heatmap tools. The current setup is deliberately privacy-light and free/self-hosted-first.

If more behavioural UX detail becomes necessary, the next approved step is Microsoft Clarity in masking-first mode. Before enabling it:

1. Review consent/privacy requirements for target countries.
2. Mask form fields and private text by default.
3. Document the public snippet and verification steps.
4. Add live browser/network checks for the Clarity script.
5. Update the privacy page before deployment.

## Report commands

```bash
python3 automation/business_review.py --period daily --write
python3 automation/heatmap_report.py --write
```

## Interpretation rules

- Page views without 50%+ scroll: tighten hero promise and above-fold CTA.
- Scrolls without clicks: improve CTA contrast, wording, and bridge sections.
- Clicks without signups: improve lead magnet specificity and form trust cues.
- Product clicks without signups/sales: add stronger email/product bridge.
- Social traffic with weak section views: align post promise to the landing page hero.
